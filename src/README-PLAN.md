# FitTrack Pro plan

Weekly program for the current goal: build a firmer physique and general strength with dumbbells, using four training days plus recovery.

- Monday: Full Body A
- Tuesday: Recovery
- Wednesday: Full Body B
- Thursday: Recovery
- Friday: Full Body C
- Saturday: Active Recovery + Core
- Sunday: Rest

The app reads `assets/exercises.json` as the single source of truth for the weekly plan and exercise images.
