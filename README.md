# FitTrack — Personal Fitness Tracker

เว็บแอปส่วนตัวสำหรับวางแผนและติดตามการออกกำลังกาย

## ฟีเจอร์ MVP
- Dashboard สรุป Workout, เวลา, Streak และจำนวนเซ็ต
- ตาราง Full Body Workout พร้อมเซ็ต/ครั้ง/น้ำหนักแนะนำ
- บันทึกน้ำหนักดัมเบลของแต่ละท่า
- ติ๊กท่าที่ทำแล้วและบันทึก Workout
- ประวัติการออกกำลังกาย
- Progress ของแต่ละท่า
- Responsive รองรับมือถือ
- เก็บข้อมูลด้วย `localStorage` ไม่ต้องมี backend

## ใช้งาน
เปิด `index.html` ได้โดยตรง หรือ deploy repository นี้ด้วย GitHub Pages

## Workout เริ่มต้น
1. Goblet Squat — 3 × 10–12
2. Dumbbell Romanian Deadlift — 3 × 10–12
3. Dumbbell Floor Press — 3 × 10–12
4. One-arm Dumbbell Row — 3 × 10/ข้าง
5. Dumbbell Shoulder Press — 3 × 8–10
6. Plank — 3 × 30–45 วินาที

> น้ำหนักเป็นจุดเริ่มต้นทั่วไป ควรเลือกน้ำหนักที่ควบคุมฟอร์มได้ดี
